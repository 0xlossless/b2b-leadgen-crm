# B2B LeadGen CRM — Phase 1 MVP Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build a fully functional CRM dashboard with lead database, scoring engine, pipeline Kanban, analytics, and a Google Maps scraper — all self-contained with SQLite (no external services needed).

**Architecture:** Next.js 14 App Router monolith with SQLite (via Drizzle ORM) for zero-config local dev. Server Actions for mutations, tRPC-style API routes for data fetching. shadcn/ui component library with dark mode. Background scraper runs as an API route triggered from the dashboard.

**Tech Stack:**
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui + Radix UI
- Drizzle ORM + SQLite (better-sqlite3) — zero config, no Supabase needed for MVP
- Recharts for charts
- dnd-kit for Kanban drag-and-drop
- Zod for validation
- Playwright for Google Maps scraping

**Why SQLite for MVP:** No database server to install/configure. Single file. We migrate to Supabase/Postgres in Phase 2 — Drizzle makes the switch trivial.

## Task Breakdown

### Task 1: Project Scaffolding
- `npx create-next-app@14 b2b-leadgen` with TypeScript, Tailwind, App Router
- Install deps: drizzle-orm, better-sqlite3, @dnd-kit/core, recharts, zod, ulid
- Install shadcn/ui and init with dark theme
- Configure drizzle.config.ts pointing to data/leadgen.db

### Task 2: Database Schema & Migrations
- Write full Drizzle schema in src/lib/db/schema.ts
- Generate and run migration
- Create DB client singleton in src/lib/db/index.ts

### Task 3: Seed Data
- Write seed script with 20+ realistic leads across all stages
- Multiple industries, score tiers, pipeline stages
- Include contacts, scores, deals, and activity history

### Task 4: Layout Shell (Sidebar + Header)
- Dark mode root layout with Inter/Geist font
- Collapsible sidebar with nav: Dashboard, Leads, Pipeline, Analytics, Scraper
- Icons from lucide-react
- Mobile responsive hamburger menu

### Task 5: Command Center (Home Dashboard)
- KPI cards: total leads, hot leads, pipeline value, deals closed, avg deal size, conversion rate
- Activity feed (last 20 activities)
- Charts: leads by source (bar), score distribution (histogram), pipeline funnel

### Task 6: Lead Database View
- Server-side paginated, sortable, filterable table
- Columns: company, contact, score badge, stage, source, last activity, email status
- Bulk actions toolbar: assign, export CSV, archive
- Search with filter dropdowns (industry, score tier, stage)

### Task 7: Lead Scoring Engine
- Implement ICP scoring algorithm in src/lib/scoring.ts
- Score breakdown per factor
- Auto-tier assignment (hot/warm/cold)
- Disqualification logic with reason codes
- API route to score/rescore individual or bulk leads

### Task 8: Pipeline Kanban Board
- 8-column Kanban using @dnd-kit
- Drag-and-drop between stages (updates DB via API)
- Deal cards with: company, contact, score badge (color-coded), deal value, last activity
- Column headers with count + total deal value
- Quick-edit modal on card click

### Task 9: Lead Profile Page
- Full firmographic data display
- Contact cards with email/phone/LinkedIn
- Activity timeline (all touchpoints)
- Score breakdown visualization
- Edit capabilities for all fields

### Task 10: Analytics & Reporting
- Funnel conversion rates (stage-to-stage)
- Source attribution chart (which sources produce best leads)
- Score distribution
- Pipeline value by stage
- Deals closed over time

### Task 11: Scraper Control Panel + Google Maps Scraper
- Form: search query, location, radius, max results
- Job queue display with status indicators
- API route that triggers Playwright-based Google Maps scraper
- Extracts: business name, address, phone, website, rating, category
- Deduplication by domain/phone fingerprint
- Auto-scores new leads after scrape

### Task 12: Seed, Polish & Ship
- Run full seed data
- Test all views end-to-end
- Fix responsive issues
- Add loading states and error boundaries
- README with setup instructions

## API Endpoints

| Method | Route | Purpose |
|--------|-------|---------|
| GET | /api/leads | List leads (paginated, filtered) |
| POST | /api/leads | Create lead |
| GET | /api/leads/[id] | Get lead detail |
| PATCH | /api/leads/[id] | Update lead |
| DELETE | /api/leads/[id] | Delete lead |
| POST | /api/leads/bulk | Bulk operations |
| GET | /api/pipeline | Get deals grouped by stage |
| PATCH | /api/pipeline/[id] | Move deal to stage |
| POST | /api/scoring/run | Score/rescore leads |
| GET | /api/analytics | Dashboard aggregations |
| POST | /api/scraper/start | Start scrape job |
| GET | /api/scraper/jobs | List scrape jobs |
| GET | /api/scraper/jobs/[id] | Job detail + results |
